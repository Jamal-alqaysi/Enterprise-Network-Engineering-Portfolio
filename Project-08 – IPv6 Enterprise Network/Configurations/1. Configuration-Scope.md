
## Overview

This directory contains the Cisco IOS configuration additions introduced in **Project 08 – IPv6 Enterprise Network**.

Only the configuration changes implemented during this project are included. The baseline configurations from **Projects 01 through 07** remain unchanged and are not repeated.

---

## Devices

- HQ-MLS01
- HQ-RTR01
- BR1-RTR01
- BR2-RTR01
- ISP-RTR01

> **Note**
>
> ISP-RTR01 was introduced in Project 06 to provide Internet connectivity. Although its configuration was not documented separately at that time, new IPv6 and OSPFv3 configuration was implemented in Project 08, therefore its project-specific configuration is included in this directory.
