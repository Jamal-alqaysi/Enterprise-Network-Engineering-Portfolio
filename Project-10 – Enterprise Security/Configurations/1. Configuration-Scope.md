
## Overview

This directory contains the Cisco IOS configuration additions introduced in **Project 10 – Enterprise Layer 2 Security**.

Only the configuration changes implemented during this project are included. The baseline configurations from **Projects 01 through 09** remain unchanged and are not repeated.

The final implemented Layer 2 security features include:

- Port Security
- Sticky MAC Address Learning
- DHCP Snooping
- PortFast
- BPDU Guard

---

## Devices

- HQ-SW01
- HQ-SW02
- HQ-SW03
- BR1-SW01
- BR2-SW01

> **Note**
>
> Dynamic ARP Inspection (DAI) and Storm Control were part of the original Project 10 security plan and were evaluated during implementation. They were excluded from the final configuration because of limitations encountered with the Cisco IOL images used in the EVE-NG lab environment. Therefore, no DAI or Storm Control configuration is included in the device configuration files.
