
## Overview

Project 04 introduced Wide Area Network (WAN) connectivity by extending the enterprise network beyond the Headquarters campus.

The implementation of Static Routing provided a clear understanding of how routers forward traffic between geographically separated sites using manually configured routes.

---

## Key Lessons Learned

- Implemented a hub-and-spoke WAN topology connecting Headquarters with two branch offices.
- Configured point-to-point WAN links using /30 IPv4 networks.
- Deployed Static Routing to enable communication between multiple remote networks.
- Verified end-to-end connectivity between Headquarters and both branch offices.
- Understood the relationship between Layer 3 routing at Headquarters and WAN edge routing.
- Practiced systematic troubleshooting by identifying and correcting a WAN interface configuration issue.

---

## Project Outcome

Project 04 successfully expanded the NorthStar Enterprise Network into a multi-site enterprise environment.

The completed WAN infrastructure and Static Routing implementation provide the routing foundation for the subsequent development of the NorthStar Enterprise Network.
