
## Overview

This directory contains the Cisco IOS configuration additions introduced in **Project 09 – First Hop Redundancy (HSRP)**.

Only the configuration changes implemented during this project are included. The baseline configurations from **Projects 01 through 08** remain unchanged and are not repeated.

---

## Devices

- HQ-MLS01
- HQ-MLS02

> **Note**
>
> HQ-MLS02 was introduced in Project 02 as part of the redundant Layer 2 architecture. In Project 09, Layer 3 functionality was enabled and the required SVIs were configured so that HQ-MLS02 could participate as the Standby HSRP gateway.
