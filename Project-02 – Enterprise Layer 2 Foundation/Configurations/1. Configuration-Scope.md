
## Overview

This directory contains the Cisco IOS configuration additions introduced in **Project 02 – Enterprise Layer 2 Foundation**.

For devices retained from Project 01, only the configuration changes introduced during Project 02 are included. The baseline configurations established in Project 01 are not repeated.

HQ-MLS02 is introduced as a new device in Project 02; therefore, its configuration file also includes the initial device configuration required to integrate it into the NorthStar Enterprise Network.

---

## Devices

- HQ-MLS01
- HQ-MLS02
- HQ-SW01
- HQ-SW02
- HQ-SW03

---

## Configuration Scope

The following Layer 2 configuration changes are implemented in this project:

- Departmental Data VLANs
- Dedicated Voice VLANs
- Management VLAN 99
- Native VLAN 999
- IEEE 802.1Q trunking
- Data and Voice VLAN assignments on user-facing interfaces
- Management IPv4 addressing
- Rapid PVST+
- Primary and secondary STP root bridge configuration
- Redundant Layer 2 uplinks

---

## Device Configuration Approach

For the devices retained from Project 01:

- HQ-MLS01
- HQ-SW01
- HQ-SW02
- HQ-SW03

The configuration files contain only the additions and changes required for Project 02.

For HQ-MLS02, which is introduced in this project, the configuration file contains both the initial device configuration and the Layer 2 configuration required for Project 02.

---

## Notes

Project 02 expands the existing infrastructure without introducing Layer 3 routing between the enterprise VLANs.

Inter-VLAN Routing, dynamic routing, DHCP, NAT/PAT, ACLs, EtherChannel, HSRP, IPv6, and advanced Layer 2 security are outside the configuration scope of this project.

Cisco IOS commands and device-specific configuration changes are stored exclusively within this directory.
