
## Overview

This directory contains the Cisco IOS configuration changes introduced in **Project 06 – DHCP, NAT & ACL Services**.

For devices retained from previous projects, only the configuration changes introduced during Project 06 are included.

ISP-RTR01 is introduced as a new device in Project 06; therefore, its configuration file also includes the initial device configuration required to integrate it into the NorthStar Enterprise Network.

---

## Devices

The following devices receive configuration changes in this project:

- HQ-MLS01
- HQ-RTR01
- BR1-RTR01
- BR2-RTR01
- ISP-RTR01

---

## Configuration Scope

The following configuration changes are implemented in this project:

- Centralized DHCP services on HQ-MLS01
- DHCP address exclusions
- DHCP pools for Headquarters and branch networks
- DHCP Relay on BR1-RTR01 and BR2-RTR01
- Public IPv4 connectivity between HQ-RTR01 and ISP-RTR01
- Simulated Internet resource on ISP-RTR01
- NAT/PAT on HQ-RTR01
- NAT inside and outside interface classification
- NAT classification ACL
- Static default route toward ISP-RTR01
- OSPF default route advertisement
- Extended branch security ACLs
- DHCP permit entries required for branch DHCP operation
- Inbound ACL application on branch LAN interfaces

---

## Device Configuration Approach

### HQ-MLS01

HQ-MLS01 is retained from the previous projects.

Only the centralized DHCP configuration introduced in Project 06 is included in its configuration file.

---

### HQ-RTR01

HQ-RTR01 is retained from the previous projects.

Its Project 06 configuration contains only the changes required for:

- Public connectivity to ISP-RTR01
- NAT/PAT
- NAT inside and outside interface classification
- NAT classification
- Static default routing
- OSPF default route advertisement

---

### BR1-RTR01

BR1-RTR01 is retained from the previous projects.

Its Project 06 configuration contains:

- DHCP Relay
- BR1-LAN-POLICY
- DHCP permit entries
- Branch security policy
- Inbound ACL application on the branch LAN interface

---

### BR2-RTR01

BR2-RTR01 is retained from the previous projects.

Its Project 06 configuration contains:

- DHCP Relay
- BR2-LAN-POLICY
- DHCP permit entries
- Branch security policy
- Inbound ACL application on the branch LAN interface

---

### ISP-RTR01

ISP-RTR01 is introduced in Project 06.

Its configuration file contains:

- Initial device configuration
- Public IPv4 connectivity to HQ-RTR01
- Loopback interface used as the simulated Internet resource

---

## Notes

Project 06 introduces centralized network services and external connectivity while preserving the existing OSPF-based enterprise routing infrastructure.

The configuration files for devices retained from previous projects contain only the commands implemented during Project 06.

The ISP-RTR01 configuration file includes both the initial device configuration and the Project 06 configuration because the device is introduced for the first time in this project.

Cisco IOS commands and device-specific configuration changes are stored exclusively within this directory.
