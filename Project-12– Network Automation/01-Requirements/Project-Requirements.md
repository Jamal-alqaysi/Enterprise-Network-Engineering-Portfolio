## Objective

Implement Python-based network automation using Netmiko to automate device management and operational verification across the existing NorthStar enterprise network.

---

## Technical Requirements

- Establish secure SSH connections to Cisco network devices using Python and Netmiko.
- Use Python dictionaries to manage device connection parameters.
- Automate Cisco IOS command execution and output collection.
- Implement Python loops and functions to manage multiple devices.
- Analyze command outputs using conditional statements.
- Implement error handling for SSH and authentication failures.
- Verify automation functionality and preserve existing network services.
- Document automation scripts, test results, and troubleshooting procedures.
---
## Scope

Project 12 focuses on implementing basic network automation within the existing NorthStar enterprise infrastructure.

The project uses the `linux-mgmt01` management host, Python 3, and Netmiko to automate SSH-based operational tasks across selected Headquarters and Branch devices.

The existing network topology, configurations, routing protocols, and enterprise services remain unchanged.

Automation activities include device connectivity, command execution, output analysis, and basic error handling.
