
## Overview

This directory contains the Cisco IOS configuration changes introduced in **Project 05 – Dynamic Routing Implementation (OSPF)**.

All participating Layer 3 devices were previously deployed and configured in Project 04. Therefore, the configuration files in this directory contain only the changes introduced during Project 05.

---

## Devices

The following devices receive configuration changes in this project:

- HQ-MLS01
- HQ-RTR01
- BR1-RTR01
- BR2-RTR01

---

## Configuration Scope

The following configuration changes are implemented in this project:

- Removal of the Static Routes configured in Project 04
- OSPFv2 process configuration
- Single-area OSPF deployment using Area 0
- Advertisement of Headquarters networks
- Advertisement of branch LAN networks
- Advertisement of WAN networks
- Advertisement of the Headquarters transit network

---

## Device Configuration Approach

### HQ-MLS01

The Project 04 Static Routes to the branch networks are removed.

OSPF is configured to advertise:

- Headquarters Data VLAN networks
- Management VLAN network
- Headquarters transit network

### HQ-RTR01

The Project 04 Static Routes are removed.

OSPF is configured across the existing WAN and Headquarters transit networks.

### BR1-RTR01

The Project 04 Static Routes are removed.

OSPF is configured to advertise the Branch 1 LAN and its WAN connection to Headquarters.

### BR2-RTR01

The Project 04 Static Routes are removed.

OSPF is configured to advertise the Branch 2 LAN and its WAN connection to Headquarters.

---

## Notes

Project 05 replaces the Static Routing implementation from Project 04 with OSPFv2.

The existing physical topology, interface addressing, VLAN architecture, and WAN infrastructure remain unchanged.

Only Project 05 configuration changes are included in this directory. Existing baseline and device configurations from previous projects are not repeated.
