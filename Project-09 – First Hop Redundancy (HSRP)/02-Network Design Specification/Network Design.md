
## Design Overview

Project 09 builds directly on the enterprise infrastructure implemented in Project 08 by introducing First Hop Redundancy Protocol (HSRP) within the Headquarters campus.

The existing enterprise topology, IPv4 and IPv6 architecture, OSPFv2, OSPFv3, NAT/PAT, ACLs, EtherChannel, Rapid PVST+, and other previously implemented enterprise services are preserved.

The primary change introduced in this project is default gateway redundancy using HSRP across the Headquarters VLANs.

To support gateway redundancy, HQ-MLS02 is enabled for Layer 3 operation and configured with VLAN interfaces required to participate as the Standby HSRP gateway.

DHCP gateway information is also updated so Headquarters clients use the HSRP virtual IP addresses as their default gateways.

---

## Network Topology

The physical enterprise topology remains unchanged from Project 08.

No additional network devices or physical links are introduced in this project.

HQ-MLS01 and HQ-MLS02 continue operating within the existing redundant Headquarters switching architecture, with HSRP providing logical default gateway redundancy between the two multilayer switches.

## HSRP Design

HSRP is implemented on all Headquarters VLANs to eliminate the default gateway as a single point of failure.

HQ-MLS01 operates as the preferred Active gateway under normal operating conditions, while HQ-MLS02 operates as the Standby gateway.

Each VLAN uses a dedicated HSRP virtual IP address as its default gateway.

The HSRP implementation includes:

- HSRP Version 2
- Active gateway on HQ-MLS01
- Standby gateway on HQ-MLS02
- One virtual gateway per VLAN
- Higher HSRP priority on HQ-MLS01
- HSRP Preemption
- Automatic gateway failover
- Automatic gateway recovery

---

## IPv4 Gateway Design

The existing HQ-MLS01 SVI addresses remain unchanged.

HQ-MLS02 is configured with a secondary Layer 3 SVI address within each Headquarters VLAN, while a new HSRP virtual IP address is used as the shared default gateway.

| VLAN | Virtual Gateway | HQ-MLS01 | HQ-MLS02 |
|------|-----------------|----------|----------|
| 10 | 192.168.10.254 | 192.168.10.1 | 192.168.10.2 |
| 20 | 192.168.20.254 | 192.168.20.1 | 192.168.20.2 |
| 30 | 192.168.30.254 | 192.168.30.1 | 192.168.30.2 |
| 99 | 192.168.99.254 | 192.168.99.1 | 192.168.99.2 |

The physical SVI addresses remain assigned to the individual multilayer switches, while the `.254` address in each VLAN becomes the shared HSRP virtual gateway.

---

## DHCP Gateway Design

The Headquarters DHCP configuration is updated so clients receive the HSRP virtual IP address instead of the physical HQ-MLS01 SVI address as their default gateway.

| VLAN | Previous Gateway | HSRP Virtual Gateway |
|------|------------------|----------------------|
| 10 | 192.168.10.1 | 192.168.10.254 |
| 20 | 192.168.20.1 | 192.168.20.254 |
| 30 | 192.168.30.1 | 192.168.30.254 |
| 99 | 192.168.99.1 | 192.168.99.254 |

This allows clients to continue using the same default gateway address regardless of which multilayer switch currently holds the Active HSRP role.

No manual client-side gateway changes are required.

## HSRP Parameters

| VLAN | Group | Active Device | Standby Device | Priority |
|------|-------|---------------|----------------|----------|
| 10 | 10 | HQ-MLS01 | HQ-MLS02 | 110 / 100 |
| 20 | 20 | HQ-MLS01 | HQ-MLS02 | 110 / 100 |
| 30 | 30 | HQ-MLS01 | HQ-MLS02 | 110 / 100 |
| 99 | 99 | HQ-MLS01 | HQ-MLS02 | 110 / 100 |

### Additional Parameters

- HSRP Version: 2
- HQ-MLS01 Priority: 110
- HQ-MLS02 Priority: 100
- Preemption: Enabled
- Virtual MAC Address: Automatically generated by HSRP

HQ-MLS01 is assigned the higher priority so that it becomes the preferred Active gateway.

Preemption allows HQ-MLS01 to automatically resume the Active role after recovering from a failure.

## Layer 3 Gateway Operation

HQ-MLS01 retains its existing Layer 3 SVI addresses for the Headquarters VLANs.

HQ-MLS02 is enabled for Layer 3 operation and configured with dedicated SVI addresses for VLANs 10, 20, 30, and 99.

HSRP operates between the corresponding VLAN interfaces on HQ-MLS01 and HQ-MLS02.

The physical SVI addresses identify the individual multilayer switches, while the HSRP virtual address represents the logical default gateway used by clients.

---

## Routing Design

Project 09 does not introduce a new routing protocol.

The routing architecture implemented in previous projects is preserved while HSRP adds redundancy specifically at the default gateway layer.

HQ-MLS02 is enabled for Layer 3 forwarding as required to participate in the Headquarters gateway redundancy design.

No new routing protocol is introduced as part of the HSRP implementation.

## Failover Operation

During normal operation, HQ-MLS01 serves as the Active HSRP gateway and HQ-MLS02 remains in the Standby state.

Because both multilayer switches participate in the same HSRP groups, HQ-MLS02 can assume the Active gateway role if the current Active gateway for a VLAN becomes unavailable.

Clients continue using the same HSRP virtual IP address as their default gateway during the role transition.

No client-side gateway reconfiguration is required.

When HQ-MLS01 becomes available again, HSRP Preemption allows it to resume the preferred Active gateway role.

HSRP failover and recovery were validated for VLAN 10 during project verification.

---

## Design Summary

Project 09 introduces First Hop Redundancy Protocol (HSRP) to eliminate the default gateway as a single point of failure within the Headquarters network.

HQ-MLS01 operates as the preferred Active gateway with a priority of 110, while HQ-MLS02 operates as the Standby gateway with a priority of 100.

HSRP virtual addresses ending in `.254` are configured for VLANs 10, 20, 30, and 99 and are distributed to clients as their default gateways through DHCP.

The design provides automatic gateway failover and recovery while preserving the cumulative enterprise infrastructure and services implemented in previous projects.
