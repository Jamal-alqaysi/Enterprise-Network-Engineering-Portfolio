
## Overview

This directory contains the Python automation scripts developed in **Project 12 – Network Automation** using Netmiko.

The project focuses on automating SSH connectivity, Cisco IOS command execution, interface verification, and basic error handling.

The existing network configurations from **Projects 01 through 11** remain unchanged.

The configuration files include:

- `project12.py` – Final multi-device automation script.
- `project12_single_device_backup.py` – Initial single-device automation script.

## Devices

- HQ-MLS01
- HQ-RTR01

**Automation Host:** linux-mgmt01

---

> **Note**
> 
> Project 12 focuses exclusively on basic network automation and operational verification using Python and Netmiko.
> 
> No Cisco IOS configuration changes were made during the project. All automation tasks used read-only verification commands.
> 
> SSH passwords are entered securely using `getpass()` and are not stored in the Python scripts.
