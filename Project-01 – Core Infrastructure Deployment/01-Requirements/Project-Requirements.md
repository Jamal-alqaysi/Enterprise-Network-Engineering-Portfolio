

# Project 01 – Core Infrastructure Deployment

## Overview

Project 01 establishes the foundational infrastructure of the NorthStar Enterprise Network.

The objective is to deploy a simple, scalable, and well-structured enterprise network that serves as the baseline for all subsequent projects.

The network consists of one Headquarters multilayer switch, three access switches, and six enterprise workstations operating within a single IPv4 network.

This project focuses on building the initial physical infrastructure, configuring basic device management, enabling secure SSH access, and verifying Layer 2 connectivity without introducing advanced enterprise switching or routing technologies.

---

## Objectives

- Build the initial NorthStar Enterprise Network infrastructure.
- Deploy one Headquarters multilayer switch.
- Deploy three enterprise access switches.
- Connect six enterprise workstations.
- Configure a single IPv4 network.
- Configure basic network device management.
- Configure secure remote administrative access using SSH.
- Verify end-to-end Layer 2 connectivity.
- Establish the baseline infrastructure for future enterprise networking projects.

## Project Scope

### Included

- Enterprise physical infrastructure deployment
- Basic switch configuration
- Static IPv4 addressing
- Device management configuration
- SSH remote management
- Layer 2 connectivity verification

### Excluded

The following technologies are intentionally excluded from Project 01 and are introduced in subsequent projects:

- VLANs
- Management VLAN
- Native VLAN
- IEEE 802.1Q Trunking
- Inter-VLAN Routing
- Static Routing
- OSPF
- DHCP
- NAT/PAT
- ACLs
- EtherChannel
- Rapid PVST+
- IPv6
- HSRP
- Enterprise Layer 2 Security

---

## Expected Outcome

Upon completion, the NorthStar Enterprise Network will provide a stable Layer 2 infrastructure with secure network device management and end-to-end connectivity within a single IPv4 network.

The completed infrastructure serves as the baseline architecture for all subsequent projects in the Enterprise Network Engineering Portfolio.
