
## Overview

This directory contains the Cisco IOS baseline configurations implemented in **Project 01 – Core Infrastructure Deployment**.

Because Project 01 establishes the initial NorthStar Enterprise Network infrastructure, these files contain the complete baseline configuration required for each network device.

---

## Devices

- HQ-MLS01
- HQ-SW01
- HQ-SW02
- HQ-SW03

---

## Configuration Scope

The following baseline configurations are implemented in this project:

- Device hostnames
- DNS lookup disabled
- Password encryption
- Enable secret
- Local administrative account
- Console access security
- MOTD banner
- Management IPv4 addressing
- Management default gateway on access switches
- SSH version 2
- RSA 2048-bit keys
- SSH-only VTY access
- HTTP and HTTPS management services disabled

---

## Notes

These configurations establish the initial device management and security baseline for the NorthStar Enterprise Network.

Unlike subsequent projects, which contain only the configuration additions introduced during each project, Project 01 contains the complete initial baseline configuration for each network device.
