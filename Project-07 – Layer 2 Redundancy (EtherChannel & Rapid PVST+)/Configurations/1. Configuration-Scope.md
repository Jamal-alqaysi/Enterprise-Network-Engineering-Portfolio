
## Overview

This directory contains the Cisco IOS configuration changes introduced in **Project 07 – Layer 2 Redundancy (EtherChannel & Rapid PVST+)**.

Only the configuration changes introduced during Project 07 are included. Configurations inherited from previous projects are not repeated.

---

## Devices

The following devices receive configuration changes in this project:

- HQ-MLS01
- HQ-MLS02

---

## Configuration Scope

The following configuration changes are implemented in Project 07:

- Rapid PVST+ configuration
- Deterministic spanning-tree Root Bridge selection
- LACP EtherChannel between HQ-MLS01 and HQ-MLS02
- EtherChannel member-interface configuration
- Port-Channel1 configuration
- IEEE 802.1Q trunk operation across the EtherChannel
- Native VLAN 999
- Required enterprise VLANs across the EtherChannel trunk

---

## Device Configuration Approach

### HQ-MLS01

HQ-MLS01 is retained from the existing enterprise infrastructure.

Its Project 07 configuration contains only the changes required for:

- Rapid PVST+
- Primary Root Bridge role
- LACP EtherChannel
- EtherChannel member interfaces
- Port-Channel1 trunk configuration

---

### HQ-MLS02

HQ-MLS02 is retained from the existing enterprise infrastructure.

Its Project 07 configuration contains only the changes required for:

- Rapid PVST+
- Secondary Root Bridge role
- LACP EtherChannel
- EtherChannel member interfaces
- Port-Channel1 trunk configuration

---

## Notes

Project 07 introduces Layer 2 redundancy without modifying the existing Layer 3 routing, addressing, or enterprise services.

The device configuration files contain only the Cisco IOS commands implemented during Project 07.

Cisco IOS commands and device-specific configuration changes are stored exclusively within this directory.
