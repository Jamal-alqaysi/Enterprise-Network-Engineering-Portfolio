
## Overview

This directory contains the configuration additions and modifications introduced in **Project 11 – Enterprise Campus Network**.

For existing devices, only the configuration changes implemented during Project 11 are included. Baseline configurations from **Projects 01 through 10** are not repeated.

HQ-RTR02 is introduced as a new device in Project 11; therefore, its configuration includes the required initial device configuration in addition to the Project 11 routing and connectivity configuration.

---

## Devices

- HQ-RTR01
- HQ-RTR02
- HQ-MLS01
- HQ-MLS02
- BR1-RTR01
- BR2-RTR01
- ISP-RTR01
- linux-mgmt01

---

## Configuration Scope

Project 11 configuration changes include:

- Secondary Headquarters edge router
- Additional Headquarters Layer 3 links
- Backup Branch WAN links
- OSPFv2 preferred and backup path selection
- OSPFv3 preferred and backup path selection
- Additional IPv4 and IPv6 transit networks
- Secondary Internet connectivity
- NAT/PAT on HQ-RTR02
- OSPF default-route propagation
- Persistent IPv4 Management VLAN configuration for `linux-mgmt01`

---

## Notes

HQ-RTR02 is a new device introduced in Project 11, so its file includes the required initial device configuration and the routing, IPv4, IPv6, NAT/PAT, and Internet connectivity configuration implemented for the final integration.

For all existing network devices, only commands added or modified during Project 11 are included.

The `linux-mgmt01` file contains only the persistent IPv4 Management VLAN configuration introduced during Project 11.

Existing configurations from previous projects are not duplicated in this directory.
