
## Overview

This directory contains the Cisco IOS configuration additions introduced in **Project 04 – WAN Connectivity & Static Routing**.

For devices retained from previous projects, only the configuration changes introduced during Project 04 are included. Newly introduced devices include their initial baseline configuration together with the configuration required for this project.

### Existing Device

- HQ-MLS01

### New Devices

- HQ-RTR01
- BR1-RTR01
- BR2-RTR01
- BR1-SW01
- BR2-SW01

---

## Configuration Scope

The following configuration changes are implemented in this project:

- Headquarters WAN edge router deployment
- Branch router deployment
- Branch access switch deployment
- Point-to-point WAN IPv4 addressing
- Headquarters Layer 3 transit connectivity
- Branch LAN IPv4 addressing
- Static Routing between enterprise sites
- Branch Data and Voice VLAN configuration
- Branch access port configuration

---

## Device Configuration Approach

For HQ-MLS01, which is retained from the previous projects, the configuration file contains only the changes introduced in Project 04.

For the newly introduced routers and branch access switches, the configuration files contain both the initial device configuration and the configuration required for Project 04.

---

## Notes

Project 04 extends the existing Headquarters infrastructure by introducing WAN connectivity and Static Routing between Headquarters, Branch 1, and Branch 2.

The physical connection between HQ-RTR01 and HQ-MLS02 is present in the topology but remains inactive and unaddressed during this project.

Cisco IOS commands and device-specific configuration changes are stored exclusively within this directory.
