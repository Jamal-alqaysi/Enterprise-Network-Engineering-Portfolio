
## Overview

This directory contains the Cisco IOS configuration additions introduced in **Project 03 – Inter-VLAN Routing**.

Only the configuration changes implemented during this project are included. The baseline configurations from Projects 01 and 02 remain unchanged and are not repeated.

---

## Devices

- HQ-MLS01

---

## Configuration Scope

The following configuration changes are implemented in this project:

- Layer 3 routing on HQ-MLS01
- SVI configuration for VLAN 10
- SVI configuration for VLAN 20
- SVI configuration for VLAN 30
- Departmental IPv4 default gateway addressing

---

## Notes

Project 03 introduces Inter-VLAN Routing on HQ-MLS01 while preserving the existing Layer 2 infrastructure established in Project 02.

No configuration changes are introduced on the remaining enterprise switches during this project.
