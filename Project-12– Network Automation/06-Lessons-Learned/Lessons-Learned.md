
## Overview

Project 12 provided practical experience in automating Cisco network operations using Python and Netmiko within the existing NorthStar Enterprise Network.

The project demonstrated how basic Python programming concepts can be applied to real network devices through SSH-based automation.

---

## Key Lessons Learned

- **Python Fundamentals:** Applied dictionaries, lists, loops, conditional statements, and string processing to network automation tasks.
- **SSH Automation:** Used Netmiko to establish SSH connections and execute Cisco IOS commands remotely.
- **Multi-Device Management:** Automated repetitive network verification tasks across multiple devices using Python loops.
- **Output Analysis:** Used `splitlines()` and `split()` to extract and analyze interface information.
- **Error Handling:** Implemented `try/except/finally` to handle execution errors and manage SSH session cleanup.
- **Troubleshooting:** Resolved Python syntax errors and a Netmiko prompt detection issue encountered during implementation.
- **Security:** Used `getpass()` to avoid storing SSH passwords directly in the automation script.
- **Documentation:** Verified and documented automation functionality using execution results and screenshots.
---

## Final Outcome

Project 12 successfully introduced basic Python-based network automation into the NorthStar Enterprise Network.

The project strengthened practical Python programming, SSH automation, command execution, troubleshooting, and operational verification skills.

The completed implementation provides a foundation for future network automation development while preserving the existing enterprise network architecture and configurations.
